# Zeni Digital: kit da marca

Solução tecnológica para o seu dinheiro.

## Cores

| Nome | Hex |
|---|---|
| Violeta | `#4119af` |
| Violeta claro | `#7646fe` |
| Ciano | `#00cce9` |
| Branco | `#ffffff` |

Degradê principal: violeta para violeta claro (`linear-gradient(100deg, #4119af, #5a2fd6, #7646fe)`). O ciano entra como destaque.

## Tipografia

- Títulos: Geologica Bold
- Textos: Montserrat Regular

Ambas estão no Google Fonts.

## Arquivos

- `zeni-logo-quadrada.png`: logo quadrada, 512 x 512 (a que está na ferramenta VendeAI)
- `zeni-logo-192.png`: versão pequena, 192 x 192, para painéis e cabeçalhos
- `cores.json`: cores e fontes em formato de dados
- `zeni-tokens.css`: cores e fontes prontas para usar em páginas

Fonte das cores e fontes: projeto "Branding: Zeni Digital", publicado no Behance em maio de 2026.
